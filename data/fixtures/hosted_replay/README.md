# Recorded pinned-data demonstration

These are saved simulated mission records, not live satellite observations.
Twenty real historical EMIT records supply source locations only.
Source sample hashes and missing provenance are preserved in the run manifests.
Both records have byte-identical replay and verified exports in acceptance.json.
The forecast refresh changes no selection in this sample. No policy advantage,
completed holdout experiment or passed capacity gate is claimed.
Comparison output, if present, retains its own seed counts and preliminary status.
