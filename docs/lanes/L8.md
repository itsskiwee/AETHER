# L8 — Independent verification

## Implementation

- `check_schedule(plan, windows, sources, spacecraft_profiles, sensor_profile, scenario)` resolves
  every selected option only within its declared window and reports `UNKNOWN_OPTION` on mismatch.
- The checker independently initializes raw SGP4 from the raw spacecraft profile, uses Astropy
  TEME/ITRS and solar geometry with the pinned `data/eop/finals2000A.all`, and recomputes LOS at
  option start and end. Slew uses only the checker’s endpoint LOS vectors.
- Fixed/committed windows and selections are optional keyword inputs. Each committed window must
  have exactly one explicit selection; fixed acquisitions participate in temporal and resource
  checks.
- Adjacency checks use `itertools.pairwise`. Selection resolution is explicit and never relies on
  a truncating `zip`.
- `tests/golden/oracle.py` exhaustively enumerates tiny option sets and validates every candidate
  with the independent checker.
