# L5 — Planner lane status

Owner: Agent 4 (planner / original L5)

## Findings and implementation in progress

- CP-SAT had an indexing defect that could assign a spacecraft's energy coefficient to a
  different spacecraft. Energy coefficients are now built and scaled per spacecraft.
- Committed acquisitions now count toward the per-source visit limit in both CP-SAT and greedy
  scheduling. Greedy resource checks include committed acquisitions and re-evaluate every energy
  prefix after insertion.
- Greedy scheduling now applies CP-SAT's positive integer-utility cutoff. Rejection explanations
  explicitly check temporal conflicts and use `NOT_SELECTED` when a feasible candidate was not
  selected for a checked conflict or budget reason.
- First-feasible request streams are keyed per source and options before a request arrival are
  excluded. Static-priority ties use stable window IDs.
- Planner output records `runtime_s=0.0` so equal inputs serialize reproducibly. The solver's
  elapsed wall time must be collected separately from the serialized `Plan`.

## Requests to interface owners

- **L1 / L9:** the runner currently replaces planner runtime with `None`. Per the user decision,
  retain deterministic `runtime_s=0.0` in serialized plans and collect actual elapsed runtime in a
  separate evaluation metric/artifact. Please coordinate the plan contract and metric plumbing.
- **L1 / L6:** add `NOT_SELECTED` to the accepted rejection-reason vocabulary. A lower-ranked
  candidate can be individually feasible and therefore cannot honestly be called `CONFLICT`.
- **L8:** extend the independent checker interface to accept committed selections, or provide an
  equivalent way to independently validate a schedule against fixed acquisitions. Current
  `check_schedule` takes no committed selections.
