# RunRecord examples

These are schema-valid UI examples, generated by
`python -m tests.integration.build_examples` from the backend directory. Each file represents one
policy because `RunRecord.policy_id` is singular. Together they show two policies, three plan
revisions per policy, six simulated outcomes per policy, valid and rejected windows, forecast
revision cause, belief snapshots, and independent validation records.

All values in these examples are illustrative synthetic data. They are not NASA or Carbon Mapper
observations, and their example validation records are not simulation results. Use `scripts/demo.sh`
for generated offline simulation artifacts.
