# Moon surface asset

`moon-color.jpg` is the 2,048 × 1,024 color map from the
[NASA CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/).

- Download: https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg
- Credit: NASA's Scientific Visualization Studio; LRO / LROC source imagery.
- Retrieved: 2026-10-18.
- SHA-256: `f7130a1822681fa7512d7dcfd40db8c10b9ba4f06777910348698260ed7a2170`.

This local rendering asset is for visual context. NASA describes the color map
as optimized for aesthetics rather than scientific measurements. It is not a
mission observation or a planner input. The browser makes no upstream request.
